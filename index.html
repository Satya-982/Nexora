How we work

From message to launch.

  1. Brief

    Send us a DM or email with what you want to build. We reply with questions and a rough scope.

  2. Design

    We sketch the screens and flows and share them with you before any code is written.

  3. Build

    We develop in small pieces and show you working versions along the way.

  4. Launch

    We deploy it, test it on real devices and hand over everything you need to run it.
